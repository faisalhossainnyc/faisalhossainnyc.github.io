## Projects

### [Vectorscope](https://github.com/faisalhossainnyc/vectorscope)
A RAG-powered cybersecurity research tool for querying MITRE ATT&CK techniques, CVE descriptions, and threat actor profiles in natural language. Built with ChromaDB, sentence-transformers, and a hybrid retrieval pipeline.

### [Obsidian MCP Server](https://github.com/faisalhossainnyc/obsidian-mcp-server)
A Model Context Protocol (MCP) server that gives AI assistants programmatic access to Obsidian vaults. Features an in-memory cache with real-time file watching for O(1) note lookups, 28 tools spanning read, write, edit, frontmatter, tags, link validation, graph analysis, and organization, plus atomic bulk edits with automatic rollback. Compatible with Claude, Gemini CLI, Cursor, and any MCP client.
